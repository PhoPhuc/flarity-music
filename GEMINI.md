# Global UI & Design System Guidelines: Vector Icons Over Emojis

1. **Strict No-Emoji Policy**:
   - Do NOT use Unicode emoji characters (e.g. 🎧, 🎵, 🚀, 🔥, 💡, etc.) in user interfaces, buttons, badges, labels, tabs, modals, toasts, or tooltips.

2. **Vector Graphics Standard**:
   - Always use clean, consistent vector SVG icons from recognized icon libraries (such as `lucide-react`, `@heroicons/react`, `tabler-icons`, `react-icons`, or platform-native SVG icons).

3. **Aesthetic Consistency**:
   - Maintain uniform stroke widths, sizing, and design tokens across all UI components.
